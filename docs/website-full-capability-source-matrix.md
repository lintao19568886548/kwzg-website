## 1. 证据与状态规则

| 内部证据 | 含义 | 可用方式 |
| --- | --- | --- |
| E1 | 本轮在 `yizuw.cn` 只读打开并核对真实页面 | 标准页面/流程可标“已上线”；需要业务规则时标“按项目配置” |
| E2 | 真实脱敏截图、项目代码、测试或产品方明确确认 | 页面事实可标“已上线”；菜单、权限、规则类能力标“按项目配置”；设备接口标“评估接入” |
| E3 | 产品 PDF 或路线图 | 统一标“规划中”，不制作可操作后台 |
| E4 | 没有足够依据 | 仅内部记录，不公开 |

状态含义：

- **已上线**：标准系统中存在真实页面或可用流程。
- **按项目配置**：能力具备，但需结合园区资料、组织、合同、收费、审批或权限配置。
- **评估接入**：依赖服务器、数据库、硬件型号、接口协议、网络、厂商与客户授权。
- **规划中**：产品路线图方向，不作为当前标准功能承诺。
