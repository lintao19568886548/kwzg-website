# 企业级大气感视觉重构

## 设计主题

本轮统一主题为“深海经营中枢 · 朱砂智启”。设计继续使用瞰维智管既有深蓝、朱砂红和暖白品牌体系，以深海蓝承载经营中枢与系统界面，以暖白承载阅读内容，以朱砂红标记主行动、当前状态和少量东方印记。

视觉用色目标为深海蓝约 55%–60%、暖白和象牙白约 35%–40%、朱砂红约 5%，并通过低透明网格、数据轨迹和克制红色柔光建立统一纹理语言。朱砂红不承担大面积背景。

## 原页面问题与尺寸基线

重构前在 1920 × 1080 视口中的实际测量如下：

| 项目 | 重构前实测 |
| --- | ---: |
| 首屏内容版心 | 1280px |
| 页头高度 | 80px |
| 首屏高度 | 1091px |
| 主标题 | 50px / 62px |
| 首屏正文 | 18px / 32px |
| 主 CTA | 114px × 56px |
| 系统界面 | 624px × 858px |

旧版系统界面呈竖长形态，首屏高度接近 1100px，1920px 屏幕中信息密度与视觉尺度不足；页面也长期依赖相似浅色背景和小卡片，深浅节奏不明显。

## 版心与页头

- 全站主版心统一为 `min(1360px, calc(100% - 64px))`。
- 1920px 视口实测内容宽度为 1360px；1440px 视口保留约 32px 安全边距。
- 桌面页头实测 85px，品牌锁定、主导航、系统登录和预约演示在同一稳定水平线上。
- 删除旧页头顶部朱砂红细线，保留低对比底部分隔线。
- 主导航为 16px；当前页以朱砂红 2px 下划线提示；预约演示保持朱砂红实色按钮。
- 移动端页头为 65px，使用独立菜单按钮，不缩放整个桌面导航。

## 首页首屏

首页改为全宽深海蓝品牌舞台：左侧为精简后的定位标签、三行主标题、核心说明和两个 CTA；右侧为 Vue/CSS 重构的横向园区经营驾驶舱；底部由暖白能力证明带向上覆盖首屏。

1920px 视口重构后实测如下：

| 项目 | 重构后实测 |
| --- | ---: |
| 首屏内容版心 | 1360px |
| 页头高度 | 85px |
| 首屏高度 | 760px |
| 主标题 | 64px / 76px |
| 首屏正文 | 18px / 32px |
| 主 CTA | 128px × 56px |
| 系统驾驶舱 | 742px × 542px（含 1px 边框） |
| 驾驶舱最小文字 | 14px |

驾驶舱使用正面横向结构，包含九项系统模块导航、四项演示指标、经营回款进度和经营待办。所有数值继续来自项目统一安全演示数据源，并明确显示“演示数据”，没有使用生产截图或生产经营数据。

能力证明带展示九个真实系统模块、206 项功能能力、七类园区解决方案以及 SaaS＋云端私有化部署；数量由统一能力数据计算或现有项目配置得出，不展示未经证实的经营提升比例。

## 全站区块节奏

- 经营价值区改为三张大价值卡，分别对应减少空置、加快回款和跨对象协同。
- 三条业务闭环使用深蓝全宽区块和四步横向节点，不增加系统不存在的字段、状态或自动化结果。
- 九个真实系统模块保持独立来源与独立演示界面，桌面使用 272px 模块导航和宽屏内容区。
- AI 区使用深蓝背景并明确“仍在持续开发完善”，不制作虚构操作界面。
- 客户案例改为大型实景图片编排，第一张重点案例占两倍宽度，其余案例使用 3:2 画幅；映射关系保持不变。
- 科技型中小企业资质紧接案例区，以企业介绍在左、已确认资质图片在右的结构呈现。
- 页面形成深色首屏、浅色经营价值、深色业务闭环、浅色能力、深色系统展示、浅色案例和企业实力、深色最终 CTA 的交替节奏。

## 浮动客服

- 桌面端使用 56px 图标按钮，完整文字只在悬停或键盘聚焦时显示；提示文字不再换行，也不使用持续位移。
- 移动端合并为一个 52px 圆形按钮，点击后打开底部操作面板，包含联系客服、电话咨询和返回顶部。
- 企业微信二维码、微信兼容扫码拨号方案与既有联系方式保持不变。

## 响应式策略

- 1920px：1360px 版心、64px 主标题、742 × 542px 驾驶舱（含边框）。
- 1440px：1360px 版心、60px 主标题、742 × 542px 驾驶舱（含边框）。
- 1024px：约 32px 安全边距、48px 主标题、约 520px 驾驶舱；回款面板改为单列宽区，避免挤压。
- 768px：首屏转为单列，CTA 全宽，驾驶舱使用移动专用布局，模块侧栏隐藏。
- 390px：20px 安全边距、38px / 48px 主标题、16px / 28px 正文、2 × 2 核心指标和 52px 单一客服按钮。
- 所有断点均禁止 `zoom` 和整页 `transform: scale()`，优先使用 Grid 重排。

## 动效与清晰度

保留低密度磁吸粒子、低透明数据轨迹、朱砂引导线、指标计数、进度加载和区块渐入。主要文字和系统界面不使用 3D 旋转、透视或整卡缩放。`prefers-reduced-motion` 和 `?motion=off` 会关闭非必要持续动画；动效关闭后，正文、导航、表单和联系方式仍完整可见。

本轮沿用已有 Windows 中文字体清晰度整改，不新增远程字体。深色首屏、AI 区和其他深色内页的正文均使用 `#cbd6e4`，避免低对比文字。

## 视觉验收

原始尺寸截图保存在 Git 忽略目录 `private-reference/grand-visual-redesign-qa/`。验收覆盖 1920、1440、1024、768 和 390 五档，另包含产品页、解决方案页、客户案例页、桌面客服、移动客服和前后对比图。

自动化验收记录以最终执行结果为准，包含横向溢出、路由、构建、测试、控制台、Hydration、生产请求和公开目录安全检查。
