# 瞰维智管官网 A+B 动效系统

## 1. 设计原则

- 使用深蓝、砖红与暖白建立高级、稳重、克制的东方科技体验。
- “动态体验”用于解释层级、确认交互和辅助阅读，不让页面持续喧闹。
- 首页、产品和解决方案使用更明显的网格、渐变与分层进入；案例、关于、预约和隐私使用柔和内容动效；后台只保留操作反馈。
- 所有位移动画优先使用 `transform` 与 `opacity`，不改变布局尺寸，不制造文本抖动。
- 首屏标题、CTA、正文与联系方式在服务端 HTML 中直接可见；JavaScript 失效时不影响信息与表单可用性。

## 2. 集中实现

- `app/assets/css/motion.css` 统一定义持续时间、缓动、位移和动画暂停规则。
- `app/plugins/motion.client.js` 注册 `v-reveal` 与 `v-motion-active`，使用 `IntersectionObserver`，不持续监听滚动位置。
- `app/plugins/motion.server.js` 提供 SSR 指令属性，避免服务端渲染与客户端激活不一致。
- 页头用顶部哨兵的 `IntersectionObserver` 切换滚动状态；页脚使用统一滚动出现。
- `HomeMagneticParticleField.vue` 只在首页 Hero 挂载原生 Canvas 2D 点阵；粒子生成与物理更新拆分到 `app/utils/magnetic-particles.js`，所有间距、影响半径、弹性、阻尼、速度和数量上限集中配置。
- `FloatingContactBar.vue` 复用统一动效变量：服务栏轻量淡入，桌面面板淡入左移，移动遮罩与底部弹窗同步进入，返回顶部按钮淡入；没有无限循环动画。
- `QualificationSection.vue` 复用滚动出现指令与统一时长；图片、标题和字段错峰进入，低饱和金色边线只播放一次，资质大图弹窗使用轻量遮罩和缩放过渡。
- `document.visibilitychange` 只切换文档可见状态；持续背景动画在标签隐藏时暂停。

## 3. 各路由动效

| 路由 | 专属动效 |
| --- | --- |
| `/` | 深蓝网格与光点缓慢移动；Hero 背景使用深蓝为主、砖红点缀的规则磁吸点阵；标题、CTA、经营总览和内容区分层进入；首屏“园区运营工作台”进行低幅度悬浮移动，固定演示状态轻量呼吸。 |
| `/products` | 十二个能力板块分批进入；状态标签提供悬停/聚焦/点击说明；有页面证据的界面淡入切换，菜单级、接入和规划能力只使用状态卡与关系图。 |
| `/solutions` | 三类资产场景与五类岗位视角分批进入；低调线条表达阅读关联，不表示自动业务流程。 |
| `/cases` | 首屏分层进入；地区筛选与五张案例卡片平滑重排；图片懒加载、悬停轻微缩放和箭头反馈。 |
| `/cases/[slug]` | 标题、摘要和授权主图分层进入；桌面端主图轻微视差；章节渐入、阅读进度、真实系统界面标签切换、画廊与底部 CTA 进入反馈。 |
| `/service` | 实施准备卡片、六步时间轴、部署边界与 FAQ 手风琴按统一节奏进入；不使用固定周期倒计时。 |
| `/about` | 品牌、宣传语、公司、企业资质与联系信息依次进入；资质图片轻微缩放、字段错峰呈现，电话、地址和二维码轻量反馈。 |
| `/demo` | 输入聚焦、校验错误、提交中、成功和失败均有文字与克制动画；重复点击被禁用。 |
| `/privacy` | 章节渐入；由 `IntersectionObserver` 更新当前阅读章节，无粒子或强视差。 |
| `/call` | 拨号卡片一次性渐入；移动或微信环境只执行一次渐进增强式拨号尝试，状态文字更新后保留“立即拨打”链接；桌面不自动唤起。 |
| `/admin/login` | 加载、验证、成功与失败反馈过渡。 |
| `/admin/leads` | 筛选结果、详情抽屉、保存、导出与错误反馈过渡；无大屏、统计图或实时动画。 |

## 4. 降级与无障碍

- `prefers-reduced-motion: reduce` 关闭粒子式背景、位移、状态呼吸和非必要动画。
- `?motion=off` 提供稳定的自动化截图与验收模式，不使用 LocalStorage。
- 首页 Canvas 在 `prefers-reduced-motion: reduce` 或 `?motion=off` 下只绘制静态低透明度点阵，不启动 `requestAnimationFrame` 循环。
- 48rem 以下或 `update: slow` 设备关闭持续背景与呼吸效果，仅保留必要状态反馈。
- 首页 Canvas 在触屏或紧凑设备将粒子上限从 1250 降至 360、点阵间距从 26px 增至 34px，并将 DPR 上限从 2 降至 1.25；触摸空白区域只产生一次短时反馈，不拦截滚动和链接。
- 案例详情在 48rem 以下关闭主图视差；减少动态与关闭动效模式同时固定主图、卡片和画廊图片变换。
- 悬浮客服栏在 48rem 以下切换为 49px 图标入口；移动电话使用原生 `tel:` 链接。减少动态与 `?motion=off` 关闭面板位移、按钮移动和平滑返回顶部，保留即时显示、遮罩、焦点和文字状态。
- 动效不承载唯一语义：加载、成功、失败、状态与错误均有可读文字和 ARIA 状态。
- 按钮、链接、表单、标签页和画廊保留键盘焦点；画廊打开后聚焦关闭按钮，ESC 关闭并恢复原焦点。
- 移动客服弹窗打开后聚焦关闭按钮、锁定背景滚动、循环对话框内焦点；遮罩、Esc 或关闭按钮退出后焦点返回触发入口。
- 资质弹窗打开后聚焦关闭按钮、隐藏并锁定背景、限制焦点在弹窗内；遮罩、Esc、关闭按钮或路由切换关闭，普通关闭恢复到对应“查看资质”触发按钮。
- 减少动态与 `?motion=off` 会关闭资质图片缩放、一次性金色流光、弹窗缩放和位移，但保留即时显示、关闭与文字状态。
- `/call` 的减少动态模式关闭卡片位移并立即显示全部内容；它不改变一次性拨号保护、真实 `tel:` 链接、状态文字或键盘焦点。电话图标不使用无限振动、声音或持续铃声动画。

## 5. 持续动画暂停

- `.kw-tech-field` 伪元素保留既有低速背景动画；首页额外的 Canvas 点阵只在交互或回位尚未稳定时请求下一帧，粒子稳定后自动停止循环。
- 元素离开视口时由 `v-motion-active` 将 `animation-play-state` 置为暂停。
- 浏览器标签隐藏时由 `data-document-visibility="hidden"` 暂停。
- 减少动态、移动端和关闭动效模式均完全停用。
- 首页 Canvas 独立监听文档可见性，并使用 `IntersectionObserver` 在 Hero 离开视口时取消动画帧；重新可见或再次交互时按需恢复。组件卸载会清理动画帧、两个观察器、媒体查询和全部指针/可见性监听器。

## 6. 系统界面真实性边界

- 动效只覆盖已经核实的园区经营总览、招商客户、客户详情、合同管理、账单管理与报修工单。
- 不制作无页面证据的待租厂房列表、房态矩阵或独立员工移动工作台；相应产品方向只按状态卡说明，不把报修工单改称设备巡检。
- 不制作虚构趋势图、实时数据变化、智能评分、审批流或系统不存在的按钮和状态。
- AI 招商匹配按产品方确认标注“按项目配置”，其余 AI 能力逐项标注规划中；在缺少独立页面证据时不制作可操作产品界面，不动画虚构字段、匹配结果或执行状态。
- 公开界面继续保留“演示数据”标识与展示区溯源边界说明，不重复显示长段固定声明。

## 7. 性能验收记录

- 未引入 Three.js、PixiJS、particles.js 或动画运行时依赖；首页磁吸点阵使用原生 Canvas 2D，其余科技背景继续使用 CSS。
- 观察器按元素进入视口触发并及时取消观察；没有持续滚动位置监听。
- Canvas 粒子点位、尺寸、透明度和颜色使用确定性规则生成，不在绘制循环中使用随机数；`?motion=off` 输出稳定静态点阵，便于截图复现。
- Canvas 按实际容器面积生成规则网格，桌面最多 1250 个粒子、紧凑设备最多 360 个；DPR 分别限制为 2 和 1.25。平均能量连续低于阈值后停止帧循环，避免鼠标停住时持续空转。
- 本次代码验收：ESLint 通过；Vitest 共 114 项通过、9 项按既有条件跳过；Nuxt 生产构建通过；构建产物启动后 13 个公开路由均返回 HTTP 200。粒子定向测试覆盖吸附、点击增强、弹簧回位、数值上限、减少动态静态绘制、离屏/后台暂停、触摸降级与卸载清理；工作台悬浮测试覆盖首页唯一启用、后台暂停和减少动态降级。
- 本次浏览器视觉验收受内置浏览器“受信任 RPC 依赖路径校验失败”阻塞，尚未取得 1440/1024/768/390 截图、浏览器控制台与实际指针/触摸性能数据；在这些门禁补验前不创建本任务提交。
- 正式验收结果在 `docs/stage-2-report.md` 中记录；任一动效、响应式、Hydration 或性能门禁失败均不得创建 Stage 2 提交。
- 返回顶部仅使用被动滚动监听和 `requestAnimationFrame` 节流；一次更新读取滚动范围并写入 Vue 状态和 CSS 进度变量，不持续读取其他布局。
- 资质图片使用本地 WebP、显式宽高、懒加载与异步解码；移动端关于页使用较小的封面派生图，详情大图只在打开弹窗时加载。
- 拨号页不加载案例、系统界面、粒子或大型动画依赖；自动尝试由一次性闭包限制为最多 1 次，不持续监听 User-Agent、滚动或页面状态，不产生 API、数据库、Cookie、LocalStorage、外部电话服务或生产系统请求。
