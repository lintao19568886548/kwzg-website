# Logo 素材

由非公开原图确定性清理得到，均为去除烘焙棋盘格、无 EXIF/GPS 的透明派生文件：

- `kwzg-logo-horizontal.png`：浅色背景导航横版，只包含图形＋“瞰维智管”。
- `kwzg-logo-horizontal-inverse.png`：深色背景反白横版。
- `kwzg-logo-horizontal-with-tagline.png`：浅色背景完整横版，包含原宣传语。
- `kwzg-logo-horizontal-inverse-with-tagline.png`：深色背景完整反白横版，包含原宣传语。
- `kwzg-logo-symbol.png`：图形独立版。

站点 favicon 使用根目录的 `favicon.png` 与 `favicon.ico`，均由图形独立版缩放生成。当前素材为透明 PNG 派生，不是矢量重制，仍需人工矢量精修。
